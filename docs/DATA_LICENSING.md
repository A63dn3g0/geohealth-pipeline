# GeoHealth data licensing gate — 27 October 2026

## HealthStats NSW is NOT automatically licensed for a commercial GeoHealth product

The HealthStats NSW [About page](https://healthstats.nsw.gov.au/page/about) says downloadable data, graphs and maps may be used in other documents and presentations with attribution and without changes to the data, but explicitly states:

> Commercial use or resale of these downloadable files or any other information contained in HealthStats NSW is prohibited.

This restriction is expressly more specific than NSW Health's broader generic CC BY notice. Treat HealthStats NSW content as **non-commercial for this project unless NSW Ministry of Health gives explicit written permission**.

There is **no licence clearance** for sublicensing the observations, publishing commercial dashboards, or selling these government data as part of the product. Do not commit the raw/processed data into this public repository. Local verification and tests should also stay within the permitted terms. Seek advice/permission before any externally hosted demo that reproduces HealthStats content.

See also [HealthStats copyright](https://healthstats.nsw.gov.au/page/copyright), and [NSW Health copyright permission process](https://www.health.nsw.gov.au/Pages/request-for-copyright.aspx).

## Action before commercial release

1. Contact NSW Ministry of Health, describe the proposed paid dashboard/analytics, published-rate displays, transformations, forecasts, geographical coverage, licensing, hosting and redistribution.
2. Seek written permission or a usable dataset-specific licence, or identify an alternative source explicitly licensed for commercial reuse.
3. Record the response, scope, attribution language, version/date and any restrictions.
4. Check boundary-data terms separately; licensing of GeoJSON polygons is not automatically the same as HealthStats rates.

No commercial use is authorised by this documentation or by the act of downloading a file.
